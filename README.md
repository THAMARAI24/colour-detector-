Color Detection & Name Identification :

This is a simple computer vision mini project that detects and identifies colors in real time using your webcam. 
When you click anywhere on the live video feed, it displays the color name along with its RGB values.

1)Requirements:
* Python 3.x
* OpenCV
* Pandas

 2)How to Run :
1. Save the code as `color_detector_full.py`.
2. Open the terminal in the folder where the file is saved.
3. Run the command:
4. The webcam will open. Click on any color in the video window to detect it.
5. Press the letter **Q** on your keyboard to quit the program.

3)Features:
* Detects color in real time using webcam input.
* Displays the color name and RGB values on screen.
* Works without any external CSV file.
* Simple, short, and beginner-friendly project.

4)Technologies Used:
* Python
* OpenCV
* Pandas

5)Example Output
Click on different objects to detect their colors:
* Red shirt → Red R=255 G=0 B=0
* Blue wall → Blue R=10 G=20 B=240
* White paper → White R=250 G=250 B=250
